# CASINO
La idea principal de este proyecto es hacer un tragamonedas digital tomando como ejemplo el "bestiario collage" 
Ademas, dependiendo de las combinaciones de imagenes habra alguna interaccion (sonido, imagenes. texto, otras paginas) segun las imagenes al azar

## ESTILO 
Temdra luces de casino, colores intensos, símbolos clásicos, sonido caracteristico a los casinos, etc.
